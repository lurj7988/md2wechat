# Markdown 全语法展示

这是一份用于测试 `md2wechat` 转换效果的 Markdown 示例。它覆盖标题、段落、强调、链接、图片、引用、列表、表格、代码、数学公式、定义列表、目录和原生 HTML 等常见语法。

## 列表

无序列表：

- 产品目标：让 Markdown 到公众号的排版更稳定。
- 体验目标：生成后的内容可以直接复制到编辑器。
- 视觉目标：
  - 层次清楚
  - 色彩克制
  - 表格和代码块可读

有序列表：

1. 编写 Markdown。
2. 选择主题。
3. 运行转换命令。
4. 打开 HTML 并复制到公众号编辑器。

混合列表：

1. 第一阶段
   - 整理内容
   - 检查图片
2. 第二阶段
   - 生成 HTML
   - 预览样式

任务列表会转换成勾选和未勾选状态：

- [x] 标题
- [x] 表格
- [x] 数学公式
- [ ] 发布前复查
